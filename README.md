# Tecatex Aerospace - Portal Interactivo Multisección

Sitio web estático interactivo diseñado para el proyecto final aeroespacial **Tecatex Aerospace**.

## 🚀 Secciones Incluidas:
1. **Main Page**: Presentación con Luna fotorrealista, Botella en órbita con propulsión, temporizador regresivo dinámico y botones de navegación rápida.
2. **🚀 Info del Cohete**: Especificaciones técnicas, masa y dimensiones de fuselaje.
3. **🔥 Prueba Estática**: Datos de empuje del motor y telemetría de banco.
4. **🎬 Video Despegue**: Reproductor y registro audiovisual.
5. **👨‍🚀 Integrantes**: Tarjetas de identificación (gafetes de seguridad) del equipo.

## 🛠️ Publicación en GitHub Pages:
1. Sube los archivos `index.html`, `styles.css`, `script.js` y `README.md` a la raíz de tu repositorio en GitHub.
2. Ve a **Settings > Pages**, selecciona la rama `main` (root) y guarda los cambios.
